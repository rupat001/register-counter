# Register Counter

A one-page, mobile-friendly tool for closing out a cash register.

Closers weigh each coin type (or enter the coin count), enter how many of each bill they have, and the page says exactly which bills to pull so the drawer ends between **$200.00 and $200.99**.

- Coins are never pulled — only whole bills.
- Big bills come out first; $1s and $5s are kept whenever possible so the next shift has change.
- Coin weight and quantity fill each other in (grams or ounces), with an optional cup weight that is remembered on the device.
- No install or server: open `index.html` in any browser.
